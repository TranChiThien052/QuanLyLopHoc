# QuanLyLopHoc
## Vietnamese
- Phần mềm quản lý lớp học - module điểm danh
- Dùng kỹ thuật nhận diện khuôn mặt để nhận diện kết hợp với tính khoảng cách GPS để phát hiện gian lận trong điểm danh
- Đọc file SETUP.md để biết thông tin chi tiết cách cài đặt và sử dụng chương trình
## English
- Class Management Program - attendance module
- Uses facial recognition scanning combined with GPS distance calculation to detect cheating in attendance
- Read the SETUP.md file for more information on how to install and use the program
